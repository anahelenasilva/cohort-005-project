# The landing page hero shows the featured course covers

Ticket #13 asked for a left-aligned landing page that grabs attention. The hero's visual on wide screens is the featured courses' own covers, fanned out behind each other beside the headline. It is built from data the page already loads, so it needs no new image asset, and it always shows real courses on Cadence.

## Considered Options

- **A new illustration or screenshot.** Rejected: an asset to make and keep up to date, and it says nothing about the courses on offer.

## Consequences

When nothing is published the hero has no visual. Below the `lg` breakpoint the covers are hidden, and the hero is text and buttons only.
