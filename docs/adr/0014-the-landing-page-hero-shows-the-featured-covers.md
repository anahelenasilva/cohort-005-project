# The landing page hero shows the featured course covers

Ticket #13 asked for a left-aligned landing page that grabs attention. The hero's visual is the featured courses' own covers: on wide screens they fan out behind each other beside the headline, and below the `lg` breakpoint the newest cover sits alone under the buttons. It is built from data the page already loads, so it needs no new image asset, and it always shows real courses on Cadence.

## Considered Options

- **A new illustration or screenshot.** Rejected: an asset to make and keep up to date, and it says nothing about the courses on offer.
- **No visual below `lg`.** Rejected: the hero was text and buttons only on phones and tablets, which is the page the ticket said did not grab attention.

## Consequences

When nothing is published the hero has no visual.
